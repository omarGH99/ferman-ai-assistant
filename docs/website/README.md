# Website assets

Images for a portfolio page or project site. Same app screenshots as
`../screenshots/`, with extra framing.

| File | Use |
|---|---|
| `hero.png` | 2400x1500 banner: three phones with captions |
| `hero-4up.png` | 3000x1500 banner: four phones |
| `*-framed.png` | Single screenshot in a phone frame, transparent corners and shadow |
| `demo.gif` | Typing a Badini and a Sorani command; about 220 KB |

All screenshots use fictional demo data. Plain, unframed versions are in
`../screenshots/`.
